# stefano.dev

Personal developer portfolio — a single-page site built with [Astro](https://astro.build),
shipped as static HTML/CSS with a sprinkle of vanilla JS, and deployed to Cloudflare.

- **Dark, dimensional** design: interactive dot-grid canvas, drifting aurora,
  pointer-tracked card glow, scroll-reveal, optional light theme.
- **No UI framework**, no client-side router. Interactivity is plain `<script>` tags.
- **Hand-written CSS** — design tokens in `src/styles/tokens.css`, everything else
  scoped to its component.

## Editing content

All copy lives in typed data files under `src/data/` — no need to touch markup:

| File            | What it holds                                                            |
| :-------------- | :----------------------------------------------------------------------- |
| `site.ts`       | SEO title / description / canonical URL / OG image                       |
| `profile.ts`    | Name, role, location, bio, "currently" list, email, socials, résumé path |
| `projects.ts`   | Selected work (`featured: true` shows on the page)                       |
| `experience.ts` | Work history (most recent first)                                         |
| `stack.ts`      | Grouped tool lists                                                       |
| `nav.ts`        | Section order + anchor-nav labels                                        |

To add a résumé: drop a PDF in `public/` and set `profile.resume` to its path
(e.g. `/stefano-esarca-cv.pdf`). While it's `null` the button stays hidden.

The social share image is `public/og.png`. Regenerate the placeholder with
`npm run og`, or replace the file with a designed 1200×630 image.

## Commands

| Command           | Action                             |
| :---------------- | :--------------------------------- |
| `npm install`     | Install dependencies               |
| `npm run dev`     | Dev server at `localhost:4321`     |
| `npm run build`   | Build the static site to `./dist/` |
| `npm run preview` | Serve the built site locally       |
| `npm run check`   | Type-check `.astro` / `.ts`        |
| `npm run format`  | Prettier                           |
| `npm run og`      | Regenerate `public/og.png`         |

## Deploying to Cloudflare

A static Astro site needs **no adapter**. Deploy the `dist/` folder to Cloudflare Pages:

1. Push to GitHub.
2. Cloudflare dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Build settings:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Node version comes from `.nvmrc` (Cloudflare's default is 22; it will fetch
     the pinned version). Override with a `NODE_VERSION` build variable if needed.
4. Add the custom domain `stefano.dev` under the project's **Custom domains**.

Without a Git connection: `npm run build && npx wrangler pages deploy dist`.

Security and cache headers are in `public/_headers`; `public/robots.txt` points at the
sitemap generated by `@astrojs/sitemap`.

> If the canonical domain changes, update `site` in `astro.config.mjs`,
> `site.url` in `src/data/site.ts`, and the `Sitemap:` line in `public/robots.txt`.
